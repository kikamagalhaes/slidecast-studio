# SlideCast Studio 1.2.0

- Painéis com bordas discretas, sem contornos herdados pelos textos; botões maiores e controles mais confortáveis.
- Interface desktop com temas claro e escuro persistentes.
- Editor com fonte PDF ou MP4 e até quatro faixas de áudio independentes.
- Prévia real, ajustes de volume/início/silêncio, projetos e exportação MP4.
- FFmpeg e ffprobe incluídos para importar e exportar sem instalação separada dessas ferramentas.
- Integração das novas áreas de captura e direção de aula pela linha do tempo já presentes no repositório.
- Correção da duração dos vídeos gerados a partir de slides.

## Downloads

Windows x64: extraia o ZIP inteiro e execute `SlideCastStudio/SlideCastStudio.exe`.
Linux x64: extraia o TAR.GZ e execute `SlideCastStudio/SlideCastStudio`.
macOS 15 Apple Silicon: abra o DMG e copie o aplicativo para Aplicativos.

São pacotes portáteis/aplicativo empacotado; não há assistente MSI/DEB/RPM. O pacote Linux é construído em Ubuntu 24.04 (glibc 2.39). O pacote Windows é destinado a Windows 10/11 x64. Sistemas mais antigos não foram certificados. Os pacotes não têm assinatura comercial de código.

Cada plataforma é validada no respectivo runner com a aplicação empacotada: ferramentas de mídia internas, presença dos módulos de captura/áudio da plataforma, render PDF/MP4 com quatro faixas e abertura Qt em ambos os temas. As evidências `*-self-test.json` e os arquivos SHA256 acompanham os downloads. Os testes são automatizados/offscreen; câmera, microfone e captura da tela exigem validação com dispositivos e permissões reais.

A compra e a ativação de licença desktop ainda não estão implementadas. Este download não configura uma licença comercial nem reutiliza a assinatura antiga do estúdio web. Nenhum preço ou período promocional é anunciado nesta release.
